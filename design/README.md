# 共享视觉 Token 与品牌资产目录（`design/`）

本目录托管 Cyrenet OS 双层 UI 共同引用的设计真源（默认适用 `Apache-2.0`，详见 [UIDESIGN.md](../UIDESIGN.md) 与 [ADR-0002](../docs/adr/0002-dual-layer-ui-architecture.md)）：

- `tokens/`：来源色板、字体、间距、圆角与 `--cn-*` CSS 变量定义（同时映射到 `themes/luci-theme-cyrenet/` 与 `ui/`）。
- `assets/`：原创涟漪/星轨 Logo、favicon 与受审查的静态视觉资产（严禁放入未经授权的第三方商业素材或游戏官方立绘）。
